# 0001 — Record architecture decisions

- **Status:** Accepted
- **Date:** 2026-10-30

## Context

The project is open source and will be built by people who were not present when early choices
were made. Without a record, decisions get re-argued or silently reversed.

## Decision

Record significant decisions as ADRs in `docs/adr/`, using `template.md`, numbered in order.

## Consequences

Contributors can find why things are the way they are. A PR that reverses a recorded decision
must include a new ADR.
