# 0006 — Apache-2.0 licence

- **Status:** Accepted
- **Date:** 2026-10-30

## Options

1. MIT — permissive, no patent grant.
2. **Apache-2.0** — permissive, explicit patent grant, contributions licensed under the same
   terms by default (section 5).
3. AGPL-3.0 — anyone hosting a modified version must publish their changes.

## Decision

Apache-2.0, full text in `LICENSE`.

## Consequences

Anyone, including companies, can use, modify and host it, including privately modified
versions. Contributions are accepted under Apache-2.0 without a separate CLA.
