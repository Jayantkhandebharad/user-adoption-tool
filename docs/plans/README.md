# plans

Roadmaps and milestone plans. A plan lists scope, order and "done when" criteria; detailed
designs go in [`../specs/`](../specs/), and decisions with alternatives go in [`../adr/`](../adr/).

| Plan | Status |
|---|---|
| [`mvp.md`](mvp.md) | Active — MVP (SDK + Studio + Flows), milestones M0–M5 |

Name new plans after their scope (`phase-2.md`, `builder-extension.md`). Mark a plan
*Done* or *Superseded* in this table rather than deleting it.
