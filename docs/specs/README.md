# specs

One spec per feature or contract, written before (or alongside) the code that implements it.
Copy [`template.md`](template.md) to `NNNN-short-title.md` (next free number) and open a PR.

A spec is accepted when its PR is merged. Update it when the implementation changes the design;
mark it *Superseded* and link the replacement instead of deleting it.
